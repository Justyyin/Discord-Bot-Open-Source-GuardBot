# Contributing

Bug reports, ideas and pull requests are welcome.

- Open an issue on GitHub or write to Discord: justyyin
- One topic per pull request, keep the existing code style
- Do not commit tokens, `.env`, `settings.json` or the `data` folder
- Keep the copyright headers and the author credit in the source files
- Run `python -m compileall guardbot main.py` before you open a pull request
